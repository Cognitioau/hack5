## Draft submission description

Zombie Hand turns deliberate browsing gestures into Obsidian captures. Hold Shift or Ctrl and circle to capture a highlighted passage with its source. It preserves text, image files or visible crops, and YouTube moments with available or imported timestamped captions. A bundled local model retrieves related thoughts without an AI API key. Saves are recoverable, conflicts stay visible, and optional media modules can be removed. Gaze calibration is experimental.
