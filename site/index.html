Zombie Brain
Hackyard #5↗ Download

A Chrome extension · Hackyard Yard #5: Haunted

Circle a thought. Bury it in Obsidian. It comes back.

Hold Shift and draw a loop round any passage. Zombie Brain drags it, with its source, into your Obsidian vault. Later, when a page comes close in meaning to something you buried, the related note rises as a ghost. It runs locally, with no AI key.

Download for Chrome

Developer build · Chrome 120+

Raise it in Chrome

  1. Dig it up

    Download the zip and unzip it. Chrome loads the folder, not the zip.

  2. Load it unpacked

    Open chrome://extensions, switch on Developer mode, choose Load unpacked and pick the unzipped folder, the one holding manifest.json.

  3. Open the vault

    In Obsidian, enable the community plugin Local REST API and copy its API key. Trust its HTTPS certificate as its README describes, or, for a local demo, turn on its HTTP listener and the extension's loopback HTTP option.

  4. Connect the grave

    Open the extension's Settings. Enter the plugin's loopback endpoint (for example https://127.0.0.1:27124), a folder for captures and the key, then Save. Saving tests the vault and says whether sync is on.

  5. Feed it

    Pin the extension, click it and choose Turn on everywhere. Then hold Shift or Ctrl and circle a passage, or select text and click the hand. Alt+Shift+Z grabs what's under the pointer; Esc cancels.

Captures go straight to your vault. Search and related-note recall run on a model bundled in the extension, so nothing leaves your machine for an AI service.
