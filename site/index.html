Zombie Brain

Chrome extension/Hackyard Yard #5/Haunted

Circle a thought. Bury it in Obsidian. It comes back.

Hold Ctrl and draw a loop round any passage. Zombie Brain drags it, with its source, into your Obsidian vault. Later, when a page comes close in meaning to something you buried, the related note rises as a ghost. It runs locally, with no AI key.

Download for Chrome

Developer build · Chrome 120+

Raise it in Chrome

  1. Dig it up

    Download the zip and unzip it. Chrome loads the folder, not the zip.

  2. Load it unpacked

    Open chrome://extensions, switch on Developer mode, choose Load unpacked and pick the unzipped folder, the one holding manifest.json.

  3. Open the vault

    In Obsidian, enable the community plugin Local REST API and copy the API key from its settings. For the quickest setup, also turn on its HTTP server: it listens on port 27123 and stays on this computer. To keep HTTPS instead, trust the plugin's certificate as its README describes.

  4. Connect the grave

    Open Settings from the extension's toolbar popup. Set the endpoint to http://127.0.0.1:27123 and tick Use HTTP for this numeric loopback endpoint only, or keep https://127.0.0.1:27124 if you trusted the certificate. Add a capture folder and the key, choose Save settings and allow Chrome's access prompt. Saving tests the vault and says whether sync is on. The key is forgotten when Chrome closes or the extension reloads, unless you tick Remember the key.

  5. Feed it

    Pin the extension, click it and choose Turn on everywhere. Then hold Ctrl and circle a passage, or select text and click the hand. Shift+Z grabs the whole page and Alt+Shift+Z what's under the pointer; Esc cancels.

Captures go straight to your vault. Search and related-note recall run on a model bundled in the extension, so nothing leaves your machine for an AI service.
